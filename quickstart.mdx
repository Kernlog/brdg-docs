This page walks through one transfer, 100 USDC from Base to Solana, with curl, plain JavaScript and the [TypeScript SDK](/sdk).

The base URL is `https://api.brdg.now/v1` and no API key is needed. Amounts are strings in the token's smallest unit: USDC has 6 decimals, so `100000000` is 100 USDC.

<Steps>
  <Step title="Find a route">
    List the chains a transfer can start from, then check which venues serve the route you want:

    <CodeGroup>
    ```bash curl
    curl https://api.brdg.now/v1/bridge/source-chains
    curl "https://api.brdg.now/v1/bridge/routes?fromChain=base&toChain=solana"
    ```
    ```javascript JavaScript
    const api = 'https://api.brdg.now/v1';
    const { chains } = await (await fetch(`${api}/bridge/source-chains`)).json();
    const { routes } = await (await fetch(`${api}/bridge/routes?fromChain=base&toChain=solana`)).json();
    ```
    ```typescript SDK
    import { createClient } from '@kernlog/brdg-sdk';
    const brdg = createClient();
    const { chains } = await brdg.getSourceChains();
    const { routes } = await brdg.getRoutes({ fromChain: 'base', toChain: 'solana' });
    ```
    </CodeGroup>

    ```json routes
    {
      "fromChain": "base",
      "toChain": "solana",
      "routes": [
        { "venue": "across", "enabled": true, "tokenSymbols": ["ETH", "SPX", "USDC", "USDT", "cbBTC"], "tokenSymbolCount": 5 },
        { "venue": "mayan", "enabled": true, "tokenSymbols": ["ARB", "EURC", "SOL", "USDC", "USDT", "WETH"], "tokenSymbolCount": 13 },
        { "venue": "relay", "enabled": true, "tokenSymbols": ["SOL", "USDC", "USDT"], "tokenSymbolCount": 3 }
      ],
      "generatedAt": 1789929187639
    }
    ```

    `tokenSymbols` is a sample of the tokens a venue supports on the route, and `tokenSymbolCount` is the full count. All chain keys are listed on [Chains](/reference/chains), and all venues on [Venues](/reference/venues).
  </Step>

  <Step title="Get a quote">
    Send the route, the tokens, the amount and both wallets. `recipient` is required here because Solana addresses differ from EVM ones.

    <CodeGroup>
    ```bash curl
    curl https://api.brdg.now/v1/bridge/quote \
      -H 'content-type: application/json' \
      -d '{
        "fromChain": "base",
        "toChain": "solana",
        "fromToken": "USDC",
        "toToken": "USDC",
        "amountAtomic": "100000000",
        "sender": "0x58E602386DB134b1F9B1d6d390C11A2B7b486677",
        "recipient": "3BQtHR41iDPiu9skeSVzmBDpZKcKqEEDnMn6UkbAHvZz"
      }'
    ```
    ```javascript JavaScript
    const quote = await (await fetch(`${api}/bridge/quote`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({
        fromChain: 'base', toChain: 'solana',
        fromToken: 'USDC', toToken: 'USDC',
        amountAtomic: '100000000',
        sender: '0x58E602386DB134b1F9B1d6d390C11A2B7b486677',
        recipient: '3BQtHR41iDPiu9skeSVzmBDpZKcKqEEDnMn6UkbAHvZz',
      }),
    })).json();
    ```
    ```typescript SDK
    const quote = await brdg.getQuote({
      fromChain: 'base', toChain: 'solana',
      fromToken: 'USDC', toToken: 'USDC',
      amountAtomic: '100000000',
      sender: '0x58E602386DB134b1F9B1d6d390C11A2B7b486677',
      recipient: '3BQtHR41iDPiu9skeSVzmBDpZKcKqEEDnMn6UkbAHvZz',
    });
    ```
    </CodeGroup>

    The response (shortened here) contains the best route, the fastest route and every venue that answered:

    ```json
    {
      "decisionId": "fb0798dc-97d2-41f2-8786-ace0b1c40722",
      "best": {
        "venue": "across",
        "quoteId": "j9rjf-1789929523328-a31b7f5929b9",

        "minAmountOutAtomic": "99937006",

        "feeAmountAtomic": "50000",
        "tierSavedBps": 55,
        "executable": true,
        "eligibility": "ok",

      },
      "bestByPrice": "j9rjf-1789929523328-a31b7f5929b9",
      "bestByTime": "0x1789929524ca26112477ff817da2653de7c5295b92f658dc8ba32b5b867126f7",
      "quotes": [
        { "venue": "across",       "quoteId": "j9rjf-…", "amountOutAtomic": "99937006", "estimatedSeconds": 8,    "executable": true },

        { "venue": "mayan",        "quoteId": "…",       "amountOutAtomic": "99897862", "estimatedSeconds": 3,    "executable": true },
        { "venue": "relay",        "quoteId": "0x1789…", "amountOutAtomic": "99895873", "estimatedSeconds": 1,    "executable": true },
        { "venue": "allbridge-core", "quoteId": "…",     "amountOutAtomic": "99850050", "estimatedSeconds": 1380, "executable": true },
        { "venue": "cctp",         "quoteId": "…",       "amountOutAtomic": "99781902", "estimatedSeconds": 30,   "executable": true }
      ],
      "rejected": [
        { "venue": "sideshift", "code": "invalid_input", "message": "SideShift requires the end-user IP" },
        { "venue": "owlto", "code": "above_max", "message": "amount 100000000 is above the venue maximum 99000000" }
      ],
      "fees": {
        "platform": { "bps": 5, "amountAtomic": "50000", "asset": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913", "tierSavedBps": 55 },
        "referral": null

      "expiresAt": 1789929585541

    ```

    | Field | Meaning |
    | --- | --- |
    | `best` | The quote BRDG builds by default: the highest net output among quotes a wallet can sign. |
    | `bestByPrice` | The `quoteId` of `best`. |
    | `bestByTime` | The `quoteId` of the fastest quote a wallet can sign. `null` when no venue gives an estimated time. |
    | `quotes` | Every venue that answered, best first, each with its output, minimum output, fees and estimated time. |
    | `rejected` | Venues that could not quote, each with a reason code. |

    Every `amountOutAtomic` already has the platform fee taken off. The full response is documented under [Get quote](/api-reference/quote/quote).
  </Step>

  <Step title="Build the transaction">
    Send the `decisionId` from the quote. BRDG builds `best` unless you pass a `quoteId` to pick another quote, such as the one `bestByTime` names.

    <CodeGroup>
    ```bash curl
    curl https://api.brdg.now/v1/bridge/build \
      -H 'content-type: application/json' \
      -d '{ "decisionId": "fb0798dc-97d2-41f2-8786-ace0b1c40722" }'
    ```
    ```javascript JavaScript
    const build = await (await fetch(`${api}/bridge/build`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ decisionId: quote.decisionId }),
    })).json();
    ```
    ```typescript SDK
    const build = await brdg.buildTransfer({ decisionId: quote.decisionId });
    ```
    </CodeGroup>

    ```json
    {
      "transferId": "ca0e5dee-be62-4a8d-aab9-3c8762b29281",
      "venue": "across",
      "steps": [
        { "vm": "evm", "step": "approve", "chainId": 8453, "to": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913", "data": "0x095ea7b3…", "value": "0" },
        { "vm": "evm", "step": "fee",     "chainId": 8453, "to": "0x833589fcd6edb6e08f4c7c32d4f71b54bda02913", "data": "0xa9059cbb…", "value": "0" },
        { "vm": "evm", "step": "main",    "chainId": 8453, "to": "0x28b5a0e9C621a5BadaA536219b3a228C8168cf5d", "data": "0x8e0250ee…", "value": "0" }
      ],
      "expectedOutAtomic": "99937006",
      "minOutAtomic": "99937006",
      "feeCapture": "batch",
      "feeBatch": { "chainId": 8453, "stepIndexes": [0, 1, 2] },
      "expiresAt": 1789929586118
    }
    ```

    `steps` lists every transaction to sign, in order. `expectedOutAtomic` matches the `amountOutAtomic` you were quoted. From here on, `transferId` identifies the transfer. Building the same decision again returns the same steps.
  </Step>

  <Step title="Sign and submit">
    Have the user's wallet sign each step, in order. On EVM, the wallet sets the nonce and gas (`gasLimit` is included when the venue provides one). On Solana, sign `serializedTx` exactly as returned.

    Then either send the signed transaction for BRDG to broadcast, or report the hash of a transaction the wallet already sent:

    <CodeGroup>
    ```bash Report a hash
    curl https://api.brdg.now/v1/bridge/transfers/ca0e5dee-be62-4a8d-aab9-3c8762b29281/submit \
      -H 'content-type: application/json' \
      -d '{ "txHash": "0xabab…", "step": "main" }'
    ```
    ```bash BRDG broadcasts
    curl https://api.brdg.now/v1/bridge/transfers/ca0e5dee-be62-4a8d-aab9-3c8762b29281/submit \
      -H 'content-type: application/json' \
      -d '{ "signedTransaction": "0x02f8b1…", "step": "main" }'
    ```
    ```typescript SDK
    await brdg.submitTransfer(build.transferId, { txHash: '0xabab…', step: 'main' });
    ```
    </CodeGroup>

    BRDG decodes the transaction and compares it with the steps it built. If they do not match, the request is refused and nothing is broadcast.
  </Step>

  <Step title="Track">
    <CodeGroup>
    ```bash curl
    curl https://api.brdg.now/v1/bridge/transfers/ca0e5dee-be62-4a8d-aab9-3c8762b29281
    ```
    ```typescript SDK
    const transfer = await brdg.waitForTransfer(build.transferId, { onUpdate: (t) => console.log(t.status) });
    ```
    </CodeGroup>

    A successful transfer moves through `PENDING_SIGNATURE`, `SUBMITTED` and `PENDING` to `COMPLETED`. It is finished once `status` is `COMPLETED`, `PARTIAL`, `REFUNDED`, `FAILED` or `ABANDONED`. Poll the endpoint, or use `waitForTransfer` in the SDK. [Track a transfer](/guides/track-a-transfer) explains each status.
  </Step>
</Steps>
