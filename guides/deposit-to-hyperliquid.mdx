## Before you start

- The [TypeScript project](/guides/typescript-setup), which provides `src/evm.ts`.
- A Base wallet with at least 50 USDC, and ETH to pay for gas.
- The Hyperliquid address to credit. It does not have to be yours, and it never signs anything.

## Script

This script deposits 50 USDC from Base into a Hyperliquid perps balance. Replace `0xHyperliquidAccount` with the address to credit, save the file as `src/deposit-to-hyperliquid.ts`, and run `npx tsx src/deposit-to-hyperliquid.ts`.

```typescript src/deposit-to-hyperliquid.ts
import { brdg, signEvmStep, account } from './evm';

async function main() {
  const quote = await brdg.getQuote({
    fromChain: 'base',
    toChain: 'hypercore',
    fromToken: 'USDC',
    toToken: 'USDC (perps)', // or 'USDC (spot)'
    amountAtomic: '50000000',
    sender: account.address,
    recipient: '0xHyperliquidAccount',
  });
  if (!quote.best) throw new Error(quote.rejected.map((r) => `${r.venue}: ${r.message}`).join('\n'));

  const build = await brdg.buildTransfer({ decisionId: quote.decisionId });
  let mainHash: `0x${string}` | undefined;
  for (const step of build.steps) {
    const hash = await signEvmStep(step);
    if (step.step === 'main') mainHash = hash;
  }
  if (!mainHash) throw new Error('build carried no main step');
  await brdg.submitTransfer(build.transferId, { txHash: mainHash, step: 'main' });

  const transfer = await brdg.waitForTransfer(build.transferId, {
    onUpdate: (t) => console.log(t.status, t.postStep?.creditedAmountAtomic ?? ''),
  });
  console.log(transfer.status);
}

main().catch((e) => { console.error(e); process.exit(1); });
```

## Notes

- The quote ranks two kinds of route together: venues that credit the account directly, and routes through Arbitrum where BRDG's relayer credits the account. Both need a single signature on the source chain. See [Hyperliquid](/concepts/hyperliquid).
- On a route through Arbitrum, the transfer has a `postStep`. Its `txHash` and `creditedAmountAtomic` are set once the Hyperliquid account is credited.
- The minimum deposit is 5.10 USDC for an account that is new to Hyperliquid, and 1 USDC otherwise. A route that would credit less appears in `rejected` as `below_min`, with the amount it would have delivered.

| SDK | Endpoint |
| --- | --- |
| `getQuote` | [`POST /bridge/quote`](/api-reference/quote/quote) |
