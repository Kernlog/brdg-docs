## Before you start

- The [TypeScript project](/guides/typescript-setup), which provides `src/evm.ts`.
- A Base wallet with some USDC, and ETH to pay for gas.
- Read [Private bridging](/concepts/privacy) to understand what private routing does and does not protect.

## Script

This script sends 100 USDC from Base to a different wallet on Arbitrum, using only private venues. Replace `0xRecipient` with the receiving address, save the file as `src/bridge-privately.ts`, and run `npx tsx src/bridge-privately.ts`.

```typescript src/bridge-privately.ts
import type { Hex } from 'viem';
import { account, brdg, signEvmStep } from './evm';

async function main() {
  // 1. Check that at least one private venue serves the route
  const { routes } = await brdg.getRoutes({ fromChain: 'base', toChain: 'arbitrum', privacy: true });
  if (routes.length === 0) throw new Error('no private venue serves this route');

  // 2. Quote with privacy on
  const quote = await brdg.getQuote({
    fromChain: 'base',
    toChain: 'arbitrum',
    fromToken: 'USDC',
    toToken: 'USDC',
    amountAtomic: '100000000',
    sender: account.address,
    recipient: '0xRecipient',
    privacy: true,
  });
  if (quote.emptyReason === 'no_private_route') throw new Error('no private venue quoted this amount');
  if (!quote.best) throw new Error('no private quote can be signed');
  console.log(`${quote.best.venue} delivers ${quote.best.amountOutAtomic} in ~${quote.best.estimatedSeconds}s`);

  // 3. Build. Privacy carries over from the quote.
  const build = await brdg.buildTransfer({ decisionId: quote.decisionId });

  // 4. Sign every step in order and report the bridge transaction
  let mainHash: Hex | undefined;
  for (const step of build.steps) {
    const hash = await signEvmStep(step);
    if (step.step === 'main') mainHash = hash;
  }
  if (!mainHash) throw new Error('build carried no main step');
  await brdg.submitTransfer(build.transferId, { txHash: mainHash, step: 'main' });

  // 5. Wait for delivery
  const transfer = await brdg.waitForTransfer(build.transferId, {
    onUpdate: (t) => console.log(t.status),
  });
  console.log(transfer.status, transfer.receivedAmountAtomic);
}

main().catch((e) => { console.error(e); process.exit(1); });
```

## Notes

- Several private venues are exchange desks that issue a deposit address. From an EVM or Solana wallet, BRDG turns that deposit into an ordinary transaction in `steps`, so the script above handles it like any other route.
- Venues that are not private are skipped and listed in `rejected` with the code `privacy_venue_required`.
- Expect fewer quotes, a lower output and a slower transfer than on the open route.
- Husher and SideShift need the end user's IP address. If you call the API from a server, send `userIp` on the quote. See [Rate limits](/api-reference/rate-limits#calling-the-api-from-a-server).
