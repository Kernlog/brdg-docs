---
title: Swap across chains
description: Send SOL on Solana, receive USDC on Base, and take the fastest route instead of the cheapest.
---

## Before you start

- The [TypeScript project](/guides/typescript-setup), plus `npm install @solana/web3.js bs58`.
- A Solana wallet with some SOL. Add its base58 private key as `SOLANA_PRIVATE_KEY`, and a Solana RPC URL as `SOLANA_RPC_URL`, to `.env`.

## Script

Save this as `src/swap-across-chains.ts` and run `npx tsx src/swap-across-chains.ts`.

```typescript src/swap-across-chains.ts
import 'dotenv/config';
import { createClient } from '@kernlog/brdg-sdk';
import { Connection, Keypair, VersionedTransaction } from '@solana/web3.js';
import bs58 from 'bs58';

const keypair = Keypair.fromSecretKey(bs58.decode(process.env.SOLANA_PRIVATE_KEY!));
const connection = new Connection(process.env.SOLANA_RPC_URL!);
const brdg = createClient();

async function main() {
  // 1. Quote: 0.5 SOL on Solana to USDC on Base
  const quote = await brdg.getQuote({
    fromChain: 'solana',
    toChain: 'base',
    fromToken: null, // null means the chain's native token, here SOL
    toToken: 'USDC',
    amountAtomic: '500000000',
    sender: keypair.publicKey.toBase58(),
    recipient: '0xYourBaseWallet',
  });

  // 2. Pick the fastest quote instead of the best-priced one
  const quoteId = quote.bestByTime ?? quote.bestByPrice;
  if (!quoteId) throw new Error('nothing executable');
  const row = quote.quotes.find((q) => q.quoteId === quoteId)!;
  console.log(`${row.venue}: ${row.amountOutAtomic} USDC in ~${row.estimatedSeconds}s`);

  // 3. Build that quote
  const build = await brdg.buildTransfer({ decisionId: quote.decisionId, quoteId });

  // 4. Sign the Solana transaction exactly as built. BRDG checks the signed bytes against what it built.
  const step = build.steps.find((s) => s.step === 'main');
  if (!step || step.vm !== 'svm') throw new Error('expected a Solana main step');
  const tx = VersionedTransaction.deserialize(
    step.encoding === 'base64' ? Buffer.from(step.serializedTx, 'base64') : Buffer.from(step.serializedTx, 'hex'),
  );
  tx.sign([keypair]);
  const signature = await connection.sendRawTransaction(tx.serialize());

  // 5. Report the transaction signature and wait for delivery
  await brdg.submitTransfer(build.transferId, { txHash: signature, step: 'main' });
  const transfer = await brdg.waitForTransfer(build.transferId);
  console.log(transfer.status, transfer.receivedAmountAtomic);
}

main().catch((e) => { console.error(e); process.exit(1); });
```

## Notes

- `fromToken` and `toToken` accept a symbol such as `USDC`, a token address, or `null` for the chain's native token.
- A wallet may add its own compute-budget instructions, but every instruction BRDG built must stay exactly as it is. Any other change is refused as `built_mismatch`.
- BRDG sets a recent blockhash on the transaction before returning it, so do not replace it. A Solana blockhash is only valid for about a minute, so sign and send promptly. If it expires, get a new quote.

## Endpoints used

| SDK | Endpoint |
| --- | --- |
| `getQuote` | [`POST /bridge/quote`](/api-reference/quote/quote) |

| `submitTransfer` | [`POST /bridge/transfers/{id}/submit`](/api-reference/quote/submit) |
| `waitForTransfer` | [`GET /bridge/transfers/{id}`](/api-reference/quote/transfer) |
